Overview

프로젝트 개요

강의 녹음을 올리면 텍스트 변환 · AI 요약 · 퀴즈까지 만들어 주는 학습 서비스

녹음 파일은 쌓이는데 정리와 복습으로 이어지지 않는 문제를 풀고자 했습니다. 2인 팀에서 백엔드 API와 서버 배포를 맡았습니다.

담당 업무

Backend

  • 음성 업로드 → S3 저장 → 텍스트 변환 API
  • 퀴즈 생성 · 조회 API
  • JWT 인증 필터 · Security 설정

Server

  • GitHub Actions → Docker Hub → EC2 자동 배포
  • DB · S3 · API 키를 Secrets로 관리

AI 연동

  • FastAPI 서버 (Whisper STT, Gemini 퀴즈)
  • Spring ↔ AI 서버 파일 전송

Pipeline

음성이 학습 자료가 되기까지

음성 파일은 Spring 서버와 AI 서버 두 곳을 거쳐 텍스트 · 요약 · 퀴즈가 됩니다.

  1. 음성 업로드mp3 · m4a · wav
  2. Spring BootS3 저장 · JWT 인증
  3. FastAPI 서버Spring ↔ AI 서버 파일 전송
  4. Whisper STT텍스트 변환
  5. Gemini퀴즈 생성

배포

  1. GitHub Actions빌드
  2. Docker Hub이미지 푸시
  3. AWS EC2자동 배포

DB · S3 · API 키는 GitHub Secrets로 관리하고, 배포 시 컨테이너 환경변수로 주입합니다.

Troubleshooting

파일 처리 문제 해결

음성 파일이 Spring 서버와 AI 서버 두 곳을 거치면서 생긴 문제를 로그로 추적해 해결했습니다.

KEY POINT

서버 사이 경계를 명시적으로

파일 형식 · 응답 구조를 암묵적으로 맡기지 않고 직접 지정

파일 크기 로그로 어느 구간에서 깨지는지 확인

문제원인해결
mp3 업로드 시 텍스트 변환 실패
Spring → AI 서버 요청에 multipart 형식 지정이 빠지고, STT API에 파일명 · 형식 없이 전달
multipart 형식 명시, 파일명 · MIME 타입 함께 전달, 빈 파일 검증 추가
변환 결과가 JSON 문자열 그대로 화면에 노출
AI 서버의 JSON 응답을 파싱하지 않고 문자열 그대로 DB에 저장
저장 전 텍스트만 추출, 이미 저장된 기록은 조회할 때 보정
AWS · DB 접속 정보가 설정 파일에 포함
로컬과 운영 설정을 파일 하나로 관리
GitHub Secrets → 배포 시 컨테이너 환경변수로 주입
