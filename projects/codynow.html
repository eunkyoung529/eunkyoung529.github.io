Overview

프로젝트 개요

날씨, 취향, 스타일 정보를 종합해 SPA 브랜드 상품을 직접 추천해주는 서비스입니다.

LLM · RAG로 옷 이미지와 날씨, 프로필 정보를 분석해 구매 링크까지 포함한 코디를 만듭니다.

System

  1. GitHub ActionsPUSH 시 자동 빌드 · 배포, Slack으로 실시간 모니터링
  2. Nginx · Gunicorn · Django메인 서버와 PostgreSQL
